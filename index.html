📝 Automated Exam Evaluation System

AI-Powered Grading with OCR, NLP & Machine Learning

🔍

OCR Technology

Advanced Optical Character Recognition to digitize handwritten and printed exam sheets from PDFs and images.

🤖

AI Evaluation

Intelligent grading using TF-IDF vectorization and cosine similarity for accurate answer comparison.

📊

Multiple Exam Types

Support for MCQs, Short Answers, and Essays with customized evaluation criteria for each type.

✍️

Grammar Checking

Built-in grammar correction and error detection for essay-type questions using TextBlob.

⚡

Instant Feedback

Get detailed feedback for each question with similarity scores and improvement suggestions.

🎯

Easy to Use

Simple web interface built with Streamlit - just upload files and get results instantly.

🛠️ Technology Stack

Python Streamlit Tesseract OCR pdfplumber Scikit-learn NLTK TextBlob TF-IDF

🚀 Quick Setup

Step 1: Clone the repository

git clone https://github.com/varungupta132/ML_hackathon.git
cd ML_hackathon

Step 2: Install dependencies

pip install -r requirements.txt

Step 3: Install Tesseract OCR

Download and install from: Tesseract GitHub

Step 4: Run the application

streamlit run app.py
