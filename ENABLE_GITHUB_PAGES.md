## **Method 1: Via GitHub Website (Easiest - 2 minutes)** 

### Step 1: Open Your Repository
Click this link: **https://github.com/varungupta132/ML_hackathon**

### Step 2: Go to Settings
- Look at the top of your repository page
- Click on **"Settings"** tab (rightmost option in the menu)

### Step 3: Find Pages Section
- On the left sidebar, scroll down
- Click on **"Pages"** (under "Code and automation" section)

### Step 4: Enable GitHub Pages
You'll see a section called "Build and deployment":

1. **Source**: Select **"Deploy from a branch"**
2. **Branch**: 
   - Select **"main"** from the first dropdown
   - Select **"/ (root)"** from the second dropdown
3. Click the **"Save"** button

### Step 5: Wait for Deployment (1-2 minutes)
- Refresh the page after ~1 minute
- You'll see a green box at the top saying:
  > "Your site is live at https://varungupta132.github.io/ML_hackathon/"

### Step 6: Visit Your Site! 🎉
Click the link or visit: **https://varungupta132.github.io/ML_hackathon/**

## **Troubleshooting:**

### Issue: "Pages" option not visible
- Make sure you're logged into GitHub
- Make sure it's your repository (you need write access)

### Issue: Site shows 404
- Wait 2-3 minutes (GitHub needs time to build)
- Make sure branch is set to "main" and "/ (root)"

### Issue: Site not updating
- Clear your browser cache (Ctrl + F5)
- Wait a few more minutes
